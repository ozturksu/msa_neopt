# MSA-NeOpt
Multi-Scale Attention-Enhanced Neural Optimizer for Peak Demand Management

MSc Data Analytics — National College of Ireland
Student: Süleyman Öztürk · x24286401

## Research Questions

**RQ1:** To what extent does replacing the single-scale Transformer backbone in NeOpt with a Multi-Scale Attention CNN improve the economic performance of battery storage dispatch for Demand Charge Reduction on EirGrid historical data?

**RQ2:** To what extent is dispatch quality driven by the SPO+ training objective, rather than by attention-based, convolutional, or recurrent backbone architecture choice?

## Background

Large electricity consumers in Ireland face demand charges under the Irish Single Electricity Market (SEM), where a single 15-minute peak can account for up to 70% of a monthly electricity bill. Battery storage can eliminate this peak — but only if dispatched at exactly the right moment.

The standard approach (Predict-then-Optimise, PTO) trains a model to minimise forecast error, then passes that forecast to a separate optimiser. The problem: a forecast that is accurate on average can still be wrong at the critical 15-minute slot that determines the monthly peak.

Decision-Focused Learning (DFL) fixes this by training the model directly on the cost of the dispatch decision, not on forecast error. This project also tests whether that effect depends on backbone architecture (RQ2) by training the same SPO+ objective on three structurally different backbones — attention-based, convolutional, and recurrent.

## Results

3-seed test-set results (mean ± 1 standard deviation, in percentage points):

| Model | Loss | Test Regret (%) | Peak Reduction (%) | LP-Oracle Regret (%) | Params |
|---|---|---|---|---|---|
| PTO (MultiDeT) | MSE | 1.35 ± 0.11 | 7.25 | 1.89 | 4.20M |
| SSPO Ablation | Surrogate | 0.97 ± 0.08 | 9.54 | 5.24 | 2.49M |
| **MSA-NeOpt (Ours)** | SPO+ | **0.20 ± 0.22** | 18.94 | 1.31 | **0.64M** |
| GRU-NeOpt | SPO+ | 0.25 ± 0.12 | **22.09** | **0.34** | 0.63M |
| NeOpt (SPO+) | SPO+ | 0.27 ± 0.30 | 20.61 | 0.54 | 2.49M |

**Key finding:** MSA-NeOpt achieves 6.75× lower regret than the MSE baseline using 74% fewer parameters than the single-scale Transformer it replaces. More importantly, once evaluated across three seeds rather than one, all three SPO+-trained architectures — attention (NeOpt), recurrent (GRU-NeOpt), and convolutional (MSA-NeOpt) — converge to statistically overlapping dispatch quality, while remaining clearly separated from the MSE-trained and surrogate-loss baselines. This indicates the training objective, not backbone architecture, is the primary driver of dispatch quality. An earlier single-seed comparison had suggested one architecture was dramatically superior; this did not replicate under multi-seed testing.

```bash

cd msa_neopt
conda create -n predopt310 python=3.10
conda activate predopt310
python -m pip install -r requirements.txt
```

## Code Provenance

All code traces to published sources with documented changes:

| Component | Source | Changes |
|---|---|---|
| SPO+ loss | PredOpt/predopt-benchmarks, `Energy/Trainer/diff_layer.py` | Normalised forward; negated backward sign; solver arg removed |
| MultiDeT | wangc1073/multidet (Wang et al. 2022) | 13→19 features; seq_len 72→672; single decoder head |
| PatchTST backbone | yuqinie98/PatchTST (Nie et al. 2023), configured per Kim et al. (2025) Section III-A | patch_len=16, stride=8, d_model=128 |
| GRUBackbone | PyTorch `nn.GRU` per Cho et al. (2014) | Standard 2-layer GRU; final hidden state → linear head; wrapped in SPO+ loop |
| **MSABlock** | **Original design for this study** | Motivated by Debnath et al. (2026) and Sajjad et al. (2020) — **not a port of either**. Their architectures use sequential same-kernel convolutional blocks at hourly resolution; MSABlock uses four parallel branches at different kernel sizes at 15-minute resolution, with no recurrent component. |
| LP solver | Kim et al. (2025), Equations 7–14 | Implemented using cvxpy + GLPK |

## Key Equations

**SPO+ forward loss:**

$$\mathcal{L} = \frac{1}{B}\sum_{i=1}^{B} \frac{(\hat{p}_i - p_i^*)_+}{p_i^*}$$

**SPO+ backward gradient:**

$$\frac{\partial \mathcal{L}}{\partial \hat{y}_{i,t}} = \frac{s(2\hat{y}_i - y_i) - s^*(y_i)}{H}$$

**Relative regret (primary metric):**

$$\text{Regret}_i = \frac{(\hat{p}_i - p_i^*)_+}{p_i^*} \times 100$$

where $\hat{p}_i$ is the greedy dispatch peak from the model's prediction, $p_i^*$ is the oracle peak from perfect foresight, and $H = 96$ slots (24 hours at 15-minute resolution).
